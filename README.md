# 포트폴리오 플래너

국내·미국 종목과 ETF를 검색하고, 계좌별 투자 목표와 성장주·배당주·하이브리드주 비중을 정리하는 정적 웹 앱입니다. 빌드 과정 없이 GitHub Pages 같은 정적 웹 호스트에 배포할 수 있습니다.

## 포함 파일

배포할 때 아래 파일을 같은 저장소의 루트에 둡니다.

- `index.html`
- `stock-universe.js`
- `html2canvas.min.js`
- `jspdf.umd.min.js`
- `.nojekyll`
- `.github/workflows/deploy-pages.yml`

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 위 파일을 저장소에 올립니다.
2. 저장소의 **Settings → Pages**에서 배포 소스를 **GitHub Actions**로 설정합니다.
3. `main` 또는 `master` 브랜치에 변경사항을 올리면 워크플로가 웹사이트를 게시합니다.
4. 저장소의 **Actions** 탭에서 배포가 완료되면 Pages URL을 확인합니다.

프로젝트 파일은 공개 저장소로 올라가며, 게시된 웹사이트는 인터넷에 공개됩니다.

## 데이터 저장과 개인정보

계좌와 포트폴리오 입력값은 서버로 전송되지 않고 각 사용자 브라우저의 `localStorage`에만 저장됩니다. 따라서 여러 사용자가 각자 이용할 수 있지만, 입력값은 브라우저와 기기 사이에 동기화되지 않습니다. 로그인, 클라우드 백업, 사용자 간 공유가 필요하면 별도 백엔드와 사용자 인증을 추가해야 합니다.

`stock-universe.js`는 국내 상장 종목 스냅샷과 국내 ETF 목록, Nasdaq Trader의 미국 거래소 상장 디렉터리를 포함합니다. 목록 최신화에는 종목 데이터 파일도 갱신해야 합니다.
